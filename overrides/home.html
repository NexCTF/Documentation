Features

Everything you need to run a CTF

From challenge to prize-giving, without stitching together ten different tools.

Challenges & scoring

Sequential challenges with prerequisites, multi-question support with per-question scoring, and text, code, multiple-choice, or long-text solutions.

Live scoreboard

Team-based scoring with configurable max team size, wrong-answer penalties, and a cached real-time scoreboard over SSE. Manual adjustments can be tied to a challenge, so teams see the reason where it applies.

Accounts & access

TOTP 2FA, API tokens scoped to per-group read/write permissions, session management for users and admins, OAuth2/OpenID Connect login, and a built-in OAuth2/OIDC server.

Fair play, with evidence

Trap flags that never score but raise a security event, hidden canary tokens that catch AI-assisted answers, per-team submission rate limits, and a full audit log streamed live.

Backup & restore

Dump the database to object storage from the admin panel or on a cron schedule with automatic pruning, and restore it in place: migrations, plugin migrations and restart included.

Plugin system

Register custom challenge types, solution strategies, scheduler jobs, and frontend components. Plugins own their DB tables via Alembic migrations.
